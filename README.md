## Project structure

- `src/` — Main application code (React components, hooks, utilities)
- `supabase/` — Database schema and migration files
- `docs/superpowers/` — Build spec, implementation plans, and technical documentation
- `public/` — Static assets (favicon, robots.txt, etc.)
- `index.html` — Entry HTML template
- `vite.config.ts` — Vite configuration
- `tsconfig.*` — TypeScript configuration files
- `.env.example` — Environment variable template

*Note: The previous `src/pages`, `src/lib`, and `src/types.ts` structure has been consolidated into the `src/` directory as the project evolved. Refer to the source code directly for current organization.*
